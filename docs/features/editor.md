# Editor: markdown formatting and AI prompt

- Markdown formatting: the Format menu (⌘B bold, ⌘I italic) calls `AppModel.format`, which sends a `MarkdownFormat` to `CodeEditor`; `MarkdownFormatter` (`StudioCore`) computes the edit (wrap, unwrap, bold+italic combos, spaces kept outside the markers) and the editor applies it through `shouldChangeText` so undo works. Only for markdown files with the editor visible.
- AI prompt: `PromptBar` (bottom of the detail panel; ⌘K via the Ask menu focuses it) calls `AppModel.askAI`, which runs `AIEditor` (`StudioCore`) = `claude -p` with a fixed system prompt per `DocumentKind` (`AIEditor.systemPrompt`), the document and instruction on stdin, `--tools ""`, `--setting-sources ""`, `--disable-slash-commands`, `--no-session-persistence`, temp cwd and `CLAUDE_CODE_DISABLE_CLAUDE_MDS=1` so the user's hooks and CLAUDE.md cannot leak into the reply (`--bare` is not used: it blocks OAuth login). The reply replaces the whole text; the old text is kept for Undo, and a result is dropped if the file changed meanwhile. Claude is found via `ToolLocator.claude()` in `claudeDirs`. Edit the system prompts to change what Claude may do.
