# Sidebar

- `SidebarView`: header (vault menu: vault list to switch, Manage Vaults…; New file and New folder icons), file search field (toggled by the rail's search icon, `AppModel.searching`/`query`), then the tree: folders and files as one tree of `TreeRow`s (folder icon + chevron, top-level folders start open, each level indents 20pt (`treeIndent`: chevron width plus gap) so files line up under their parent folder icon, guide line down each open folder), right-click menu (new file/folder, copy name/path, rename, delete). Drag a row onto a folder (or a file row, which means its parent folder, or the empty area, which means the vault root) to move it (`LibraryOperations.move`, `AppModel.move`; URLs from outside the vault are ignored, a folder cannot move into itself, an open file follows the move). Open/collapsed folders are saved per vault in UserDefaults `folderExpansion` (`FolderExpansion` in `StudioCore`); a saved choice beats the defaults (top-level folders open, ancestors of the selected file open). The sidebar has no hide button: the rail's Files icon (⌘⌃S) toggles it. New file/folder works like VS Code: `AppModel.beginNew` picks the target (`LibraryOperations.targetFolder`: focused folder, folder of a focused file, else the vault root; `sidebarFocus` is the last clicked row, cleared by clicking empty space), shows a `DraftRow` text field there, Return or blur creates it, an empty name drops it.
