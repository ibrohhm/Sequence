# Vaults and Settings

- Vaults: a vault is a named folder (`Vault`/`VaultList` in `StudioCore`, JSON at Application Support/Sequence/vaults.json; the list is reloaded before each change so windows share it). `AppModel.openRoot` registers any opened folder as a vault; `switchVault`, `createVault` (makes a folder in ~/Documents/Sequence), remove (forgets only, files stay) and rename (display name only) go through `VaultStore.update`. `VaultStore.shared` holds the list for every window; `AppModel.active` (set when a window becomes key, `WindowActivation`) is the window the Settings window acts on. `VaultsView` is the Vaults tab of the Settings window (`SettingsView`, ⌘, and the rail gear: General = theme icon buttons (sun/moon), sidebar "Show folder icons" / "Show file icons" toggles (`showFolderIcons`, `showFileIcons`, read by `TreeRow` and `DraftRow`) and the "Show AI editor" toggle (`aiEditorEnabled`, hides `PromptBar` and ⌘K), Vaults, About = version, PlantUML and Java in use (no Claude row)). The sidebar vault menu, File > Manage Vaults… and the choose-folder screen open it with `openSettings(tab: .vaults)` (`OpenSettingsAction` extension in `SettingsView.swift`; the AppKit `showSettingsWindow:` action did nothing). The theme is stored in UserDefaults `theme`; each window's `AppModel` follows changes made there. All three tabs use a grouped `Form` and the window is a fixed 480x480 so switching tabs does not resize it. The vault actions are disabled with a hint when no app window is open (`VaultStore.hasWindow`, cleared by `windowClosed`). Dialogs are native windows or alerts, never in-window sheets; system alerts (rename, delete, unsaved changes) stay as alerts.
